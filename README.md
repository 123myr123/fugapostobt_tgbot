# Fuga Post Bot

Telegram-бот для работы с пастами, рейтингами и данными взводов через Google Sheets.

## Возможности

- регистрация пользователей и проверка членства в Telegram-группах;
- просмотр паст и их оценка;
- просмотр топа паст;
- добавление новых паст;
- отправка сообщений пользователям выбранного взвода.

## Настройка и запуск

1. Установите Python и зависимости проекта (`python-telegram-bot`, `gspread` и другие используемые библиотеки).
2. Заполните `settings.json`: укажите токен Telegram-бота и ID групп.
3. Настройте доступ к Google Sheets.
4. Запустите бота командой `python app.py`.

**Подробная инструкция по созданию Google Cloud проекта, включению API и настройке авторизации:** [document/гугл.md](document/гугл.md).

В руководстве описаны оба варианта доступа к таблицам:
- Service Account — служебная учётная запись;
- OAuth 2.0 — авторизация через обычный Google-аккаунт.

## Основные команды бота

- `/start` — начать работу и проверить регистрацию;
- `/help` — помощь;
- `/my_id` — показать ID пользователя и чата;
- `/post` — просматривать пасты;
- `/top_post` — открыть топ паст;
- `/add_post` — предложить пасту;
- `/atack_time` — команда для участников взводов.

## Безопасность

Не публикуйте токен Telegram-бота, ключи Service Account, OAuth-учётные данные или другие секреты в репозитории. Храните их в локальных конфигурационных файлах, исключённых через `.gitignore`.
